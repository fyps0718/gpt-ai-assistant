# AGENTS.md — Cloud Codex 開發規則

## 專案名稱
教學大富翁（Learning Monopoly）

## 角色
你是本專案的實作者。依照規格逐步完成、測試、驗證，不要自行大幅改變遊戲方向。

## 核心原則
1. 先規劃，再實作。
2. 優先小步修改，避免一次重寫整個專案。
3. 完成後一定要驗證。
4. UI 必須適合教室大螢幕，也要支援平板與手機。
5. 遊戲規則要讓國小學生容易理解。
6. 不要以網路點擊速度決定勝負。
7. 隨機事件應盡量可測試，避免難以除錯。
8. 不直接 merge main；使用 branch / PR 工作流。
9. 不加入付費 API 或需要秘密金鑰的服務，除非任務明確要求。
10. 新增重要架構決策時，更新 `docs/PROJECT_BRIEF.md`。

## 驗收
每次任務完成至少確認：
- 頁面可以正常載入
- 沒有明顯 console error
- 主要互動可執行
- 手機寬度下不會嚴重破版
- 修改摘要清楚
- 列出仍未完成事項
