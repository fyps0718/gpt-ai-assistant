# 教學大富翁（Learning Monopoly）

這是一個給課堂使用的「大富翁式」學習遊戲專案。

## MVP 目標
- 2～6 組玩家
- 擲骰子移動
- 棋盤格包含：起點、題目、事件、獎勵、扣分、休息
- 回答題目可獲得金幣／分數
- 事件格可以觸發隨機事件
- 適合投影到教室大螢幕
- 手機／平板／電腦皆可操作
- 第一版使用純 HTML / CSS / JavaScript，避免不必要的框架依賴

## Cloud Codex 開發方式
1. 先閱讀 `AGENTS.md`
2. 再閱讀 `docs/PROJECT_BRIEF.md`
3. 依照 `tasks/` 裡的任務單實作
4. 每次改動後驗證遊戲可以正常啟動
5. 不要直接刪除既有功能

## 本機預覽
直接開啟 `index.html` 即可。

未來若導入 Vite、Supabase 或 Realtime，請先在文件中說明理由。
