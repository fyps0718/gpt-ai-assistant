# Project Brief｜教學大富翁

## 一、定位
以「大富翁」核心概念重新設計成課堂遊戲。
遊戲不使用原版商標、美術或角色資產，而是採用：
- 棋盤移動
- 骰子
- 資源累積
- 題目挑戰
- 隨機事件
- 策略選擇

## 二、教學目標
教師可將國語、數學、自然、社會或閱讀理解題目放入遊戲。
學生以小組形式遊玩，答題與策略共同影響結果。

## 三、MVP
### 玩家
- 2～6 組
- 每組有名稱、位置、金幣、分數

### 棋盤
第一版使用 20 格環形棋盤。
格子類型：START、QUIZ、EVENT、BONUS、PENALTY、REST。

### 回合
1. 目前玩家擲骰
2. 棋子移動
3. 觸發格子事件
4. 處理結果
5. 換下一組

### 勝利
第一版提供兩種模式：
- 回合制：固定回合後最高分獲勝
- 目標分數：率先達指定分數者獲勝

## 四、後續版本候選
- 題庫匯入
- 教師控制台
- 小組平板加入
- QR Code 加入房間
- Supabase Realtime
- 地產／城鎮系統
- 道具卡
- 任務卡
- 關係值／合作玩法
- Point Policy Engine 串接

## 五、禁止事項
- 不使用 Monopoly 官方圖片、角色、Logo 或受保護視覺素材
- 不將勝負建立在網速或搶按速度
- 不在未說明的情況下加入登入、付費服務或第三方追蹤
