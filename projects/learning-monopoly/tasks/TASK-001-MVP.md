# TASK-001｜完成教學大富翁 MVP

## OBJECTIVE
將目前骨架完成成可以在瀏覽器實際遊玩的教學大富翁 MVP。

## READ FIRST
- AGENTS.md
- docs/PROJECT_BRIEF.md
- index.html
- src/styles.css
- src/game.js

## REQUIREMENTS
1. 支援 2～6 組玩家。
2. 建立 20 格棋盤。
3. 玩家依序擲 1～6 點骰子。
4. 棋子移動後觸發格子效果。
5. 題目格至少內建 10 題示範題。
6. 答對加分；答錯不加分。
7. 事件格至少 8 種事件。
8. 顯示目前回合、目前玩家、各組分數與金幣。
9. 提供重新開始。
10. UI 適合 16:9 教室投影，並支援手機。

## ACCEPTANCE CRITERIA
- 打開 index.html 可以開始遊戲。
- 2、4、6 組玩家都能正常輪流。
- 玩家位置不會超出棋盤索引。
- 題目回答後會更新分數。
- 事件格能正常套用結果。
- 重開遊戲後狀態重置。
- 無明顯 JavaScript console error。

## RETURN FORMAT
完成後回報：
1. 修改摘要
2. 測試方式
3. 驗證結果
4. 已知限制
5. 下一步建議
